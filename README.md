# building-deep-neural-networks.github.io

Static GitHub Pages site for the "Building Neural Networks for Deep Learning Applications" workshop.

Live site: https://uschpc.github.io/building-deep-neural-networks.github.io/

Slide deck page: https://uschpc.github.io/building-deep-neural-networks.github.io/decks/building-neural-networks.html

The site adapts material from `uschpc/Building-NeuralNetworks`:

- Workshop slide deck and PDF
- Homepage slide deck with slide-by-slide notes
- `ANN.ipynb` Fashion-MNIST PyTorch notebook
- CARC conda setup script

Open `index.html` locally or use the live GitHub Pages site above.
